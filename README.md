## 三個最重要的發現

### 1. 台灣**沒有**「美容業可用幾 % 濃度的酸」這種法規

業界流傳的「20% 以下可以做」查無官方依據。真正的紅線是**化粧品果酸製品 pH 不得低於 3.5**。詳見 `05`。

### 2. 淺藕色不能用在文字和按鈕上

實測三組配色的 WCAG 對比度，淺藕色配白字只有 1.6–2.5:1，遠低於 4.5:1 的標準。解法是每組配色都要有**淺藕色負責氣質、深藕色負責功能**兩個層次。詳見樣稿的無障礙一節。

### 3. `hanface.com` 已經被別人註冊了

目前可註冊的有 `hanface.co`、`hanface.beauty`、`hanfaceskin.com` 等。另建議優先查 `hanface.tw`。詳見 `03`。

## 目前需要品牌主決定的事

在這些問題有答案之前，我不會開始建置網站 —— 猜錯的成本是整份文案要重寫。

| # | 問題 | 為什麼卡住 |
|---|---|---|
| **A1** | 你的營業身分是「有醫師的診所」還是「沒有醫師的美容工作室」？ | 決定網站上**每一句話**的法律紅線。同一組照片、同一個版面，兩種身分的合法寫法完全不同 |
| **B1** | 「動態式網站」你指的是能自己更新內容、有線上預約，還是有捲動動畫？ | 這三件事的成本差好幾倍 |
| **B2** | 你希望客人在網站上完成什麼動作？ | 首頁只能有一個最主要的目的 |
| **C4** | 你手上有哪些照片素材？有 logo 向量檔嗎？ | 決定視覺的可行上限。素材不足的話，最淺的那組配色就不能選 |
| **E3** | 上線後你想自己改文案嗎？ | 直接決定平台選擇 |

完整問卷見 [`docs/01-需求訪談問卷.md`](docs/01-需求訪談問卷.md)。

## 兩件不用等網站、現在就可以做的事

1. **登記 Google 商家檔案**（免費）。對實體店，Google 地圖是 IG 之外最強的本地流量來源，而且是**已經有購買意圖**的流量。行業類別選「美容/美膚」後會出現「預約」按鈕。
2. **安排一次品牌攝影**（半天約 NT$8,000–20,000）。韓系「乾淨純淨」的感覺九成來自照片。**這筆錢對成品的影響遠大於把網站平台從免費升級到付費方案。**

## 關於這些文件的可信度

- 研究時網頁全文抓取功能被封鎖，法規部分只能透過搜尋引擎對官方頁面的索引取得。**條號與方向可信，但逐字內容未經原文核對。**
- 文案定稿前建議送當地衛生局法規諮詢窗口確認（免費）。
- 所有查無官方依據的項目都在 `05` 第十節明確標註，沒有編造法條。
- 樣稿裡的對比度數字是用 WCAG 相對亮度公式實際計算的，可重現。
