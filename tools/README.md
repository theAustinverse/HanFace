# tools/

## copy-check.py — 文案違規詞檢查

在文案上線前掃描違規用語。針對**非醫療機構的美容業者**設計（也就是 HanFace 的身分），
依據台灣化粧品衛生安全管理法、醫療法、公平交易法。

### 為什麼需要這個

罰則不對稱得很誇張：醫療效能宣稱最高罰 **500 萬元**，而一次修正只要換一個詞。
人工校對三百句文案會漏，機器不會。

### 用法

```bash
# 檢查單一檔案
python3 tools/copy-check.py 文案.md

# 檢查整個目錄
python3 tools/copy-check.py mockup/

# 從剪貼簿或管線檢查（貼上一段文案立刻檢查）
pbpaste | python3 tools/copy-check.py -

# 只看統計，不看每一筆
python3 tools/copy-check.py docs/ --quiet

# 印出「可以用」的安全詞彙表
python3 tools/copy-check.py --list
```

**離開代碼**：發現高風險項目時回傳 1，否則 0。可以接進 CI 或 git hook。

### 四個風險等級

| 類別 | 依據 | 罰則 |
|---|---|---|
| `MEDICAL_EFFECT` | 化粧品衛生安全管理法第 10 條第 2 項（醫療效能） | **60 萬～500 萬元** |
| `MEDICAL_ANALOGY` | 醫療法第 84、87 條（比附醫療） | 5 萬～25 萬元 |
| `MEDICAL_HINT` | 醫療法第 87 條（暗示或影射醫療業務） | 5 萬～25 萬元 |
| `ABSOLUTE` | 公平交易法第 21 條＋化粧品法第 10 條第 1 項 | 4 萬～20 萬元 |
| `CAUTION` | 需人工判斷 | 依認定結果 |

### 跳過檢查

討論法規的文件會大量引用禁用詞，那不是違規。用標記排除：

```markdown
<!-- copycheck:ignore-file -->     整份跳過（要寫在前 30 行內）

<!-- copycheck:off -->
這一段刻意引用「換膚」「療程」來解釋法規
<!-- copycheck:on -->
```

`docs/` 底下的規劃文件都已加上 `ignore-file` 標記。

### 它會自動處理的三件事

**HTML 的程式碼區塊。** `<style>` 與 `<script>` 內容不掃描 —— CSS 的 `height: 100%`
不是絕對化用語。

**否定語氣。** 「我們**不做**診斷」是免責聲明，不是宣稱，會自動降級為需人工確認。
`❌ 達到接近診所的效果` 這種反例說明也會降級。

**句讀邊界。** 否定語氣不跨句讀 —— 「請避免曝曬。立即見效」裡的「避免」否定的是
曝曬，不是見效，所以「立即見效」仍會被判高風險。

### ⚠️ 兩個重要限制

**這個工具全綠不等於合規。** 法規的認定方法是「**整體綜合表現評價**」，不是逐字比對
關鍵字。一個頁面即使每個字都合法，若整體視覺與敘事（例如滿版對比照＋白袍人物）
傳達出醫療效果，仍會被認定違規。

**同音替代字不能規避法規。** 詞庫收錄了「煥膚」（官方違規例示用的是「換膚」），因為
在整體綜合評價下用同音字閃避幾乎不可能成功。這是保守判斷，不是明文規定。

**文案定稿前請送當地衛生局法規諮詢窗口確認 —— 免費，而且成本遠低於一次罰鍰。**

### 修改詞庫

詞庫就在 `copy-check.py` 的 `RULES` 常數裡，是一組 `(詞, 建議替代)` 的清單，
直接編輯即可。每筆規則都附了法源與罰則，改的時候請一起維護。
