# HanFace 官網｜需求訪談問卷

> 這份問卷的目的：把「我想要一個韓系乾淨風格的網站」這個模糊的想法，拆解成可以動手做的具體規格。
>
> 使用方式：不需要一次答完，也不需要每題都有答案。**標記 🔴 的題目請優先回答**，因為它們會決定整個網站的方向；沒有它們我無法往下做。標記 🟡 的會影響設計細節，🟢 的可以邊做邊決定。
>
> 「還沒想過」也是一個合理的答案 —— 直接寫「不知道」，我們再一起討論。

---

## A. 事業本體：你到底在賣什麼

這一組是所有問題裡最重要的。網站只是把你的生意講清楚，如果生意本身的樣貌還沒定，網站做出來一定會歪。

### 🔴 A1. 你的營業身分是哪一種？

這題決定了網站上**每一句文案的法律紅線**，是所有問題裡最關鍵的一題。

- [ ] （a）**醫療機構** —— 有立案的診所、有專任醫師，酸類煥膚由醫師或醫護人員執行
- [ ] （b）**美容工作室／沙龍** —— 沒有醫師，使用化粧品等級的酸類產品做保養護理
- [ ] （c）**與診所合作** —— 我負責品牌與客戶，實際療程在合作診所進行
- [ ] （d）**還在規劃，尚未營業**
- [ ] （e）其他：\_\_\_\_\_\_\_\_\_\_

**為什麼這題這麼重要：** 台灣對「醫療行為」與「美容保養」的界線管得很嚴。如果你是（b），網站上出現「治療」、「改善痘疤」、「淡斑」這類療效字眼，可能觸及醫療法或化粧品衛生安全管理法的違規宣傳；但如果你是（a），反而可以講較多、卻另外要遵守醫療廣告的規定。**同一個畫面、同一組照片，兩種身分的合法寫法完全不同。** 詳細的法規整理見 `05-法規與合規注意事項.md`。

### 🔴 A2. 目前的營運狀態？

- 有實體店面嗎？（有／籌備中／無，只做到府或快閃）
- 如果有，地點在哪（縣市與商圈就好）？幾間？
- 開業多久了？
- 目前一個月大約服務多少客人？
- 目前有幾位服務人員（含你自己）？

> 這會影響網站規模。單店單人的品牌，網站重點是「建立信任 + 收預約」；多店或多美容師，就需要分店頁、指定人員預約等結構。

### 🔴 A3. 服務項目與價格

請盡量列出你現在（或計畫）提供的所有項目，格式不拘：

| 項目名稱 | 內容簡述 | 時間 | 價格 | 是否主打 |
|---|---|---|---|---|
| 例：杏仁酸煥膚 | 清潔＋煥膚＋鎮定敷膜 | 60 分 | NT$1,800 | ✅ |
|  |  |  |  |  |

延伸問題：
- **🔴 價格要公開在網站上嗎？** （公開／只寫「起」／只寫價格區間／完全不公開，請客人詢問）
- 有課程套票、次卡、會員制嗎？
- 有「初次體驗價」或新客優惠嗎？
- 有在賣產品（保養品）嗎？如果有，是自有品牌還是代理？

### 🟡 A4. 你的客人是誰（比「25–40 歲女性」更具體一點）

- 她們最常帶著什麼困擾上門？（例：毛孔粗大、粉刺、膚色不均、痘痘肌、想定期保養）
- 她們是**上班族／自由業／家庭主婦／學生**為主？
- 客單價大約多少？多久回訪一次？
- 目前新客主要從哪裡來？（IG／朋友介紹／Google 搜尋／路過／團購平台）
- **有男性客人嗎？** 佔比大概多少？（會影響照片與文案的性別語氣）

### 🟡 A5. 你和別人不一樣的地方是什麼？

這題大家都覺得難答，但它是網站首頁的核心。可以從這幾個角度想：

- 技術上：你用的酸／儀器／手法有什麼特別？
- 體驗上：空間、服務流程、諮詢的細緻度？
- 人的因素：你的專業背景、證照、經歷？
- 理念上：你為什麼開這間店？

> 如果現在答不出來，我們可以用訪談的方式聊出來 —— 這是品牌文案的原料，不能跳過。

## B. 「動態式網站」你指的是什麼

🔴 **B1.** 你提到想做「動態式網站」，這個詞在實務上有三種完全不同的意思，請問你要的是哪些？（可多選）

- [ ] （a）**我能自己更新內容** —— 有後台可以發文章、改價格、換照片，不用每次找人改程式
- [ ] （b）**有互動功能** —— 線上預約、表單、會員登入、線上付款
- [ ] （c）**視覺上有動態感** —— 捲動時的淡入動畫、圖片視差、滑順轉場等視覺效果
- [ ] （d）**內容會自動變化** —— 例如自動抓取 IG 最新貼文顯示在網站上

> 這三件事的成本差很多。（c）純視覺動態其實用靜態網站就能做到，而且更快更便宜；（a）和（b）才真的需要後台或後端系統。我猜你想要的是 (a)+(c)+(d)，但這需要你確認。

🔴 **B2. 最重要的一題：你希望客人在網站上完成什麼動作？**

網站的成敗只看這一件事。請排出優先順序：

- [ ] 直接線上預約並選好時段
- [ ] 加 LINE 好友，之後用 LINE 聊細節與約時間
- [ ] 私訊 IG
- [ ] 打電話
- [ ] 填諮詢表單，你再回覆
- [ ] 只是看完覺得「這家看起來很專業」，先追蹤 IG

🟡 **B3.** 目前客人實際上是怎麼預約的？這個流程有什麼讓你困擾的地方？（例如：IG 訊息太多回不完、常常被問一樣的問題、被放鳥、想收訂金但不知道怎麼收）

> 網站最實際的價值，往往就是把你現在最花時間的那件事自動化。

## C. 視覺風格

🟡 **C1.** 「韓系網美風、乾淨純淨」我理解成：大量留白、低飽和度、柔和自然光、細緻的細襯線或無襯線字體、克制的動畫。**請問有沒有你看過覺得「就是這個感覺」的網站或 IG 帳號？** 給我 2–3 個連結，比任何形容詞都有用。

🟡 **C2.** 反過來 —— 有沒有你**明確不喜歡**的風格？（例：太多優惠貼紙、螢光色、密集文字、醫美診所常見的藍白冷色調、過度修圖的前後對比照）

🟡 **C3. 藕色系的濃度**。藕色從很淺的灰粉到偏深的乾燥玫瑰都算，質感差異很大。我準備了三個方向的實際樣稿供你挑選，見 `mockup/` 資料夾與 `03-視覺風格與色彩系統.md`。

🔴 **C4. 素材盤點 —— 這題會決定網站的質感上限，比選什麼平台重要得多。**

- 有品牌 logo 嗎？（有向量檔／只有圖片檔／沒有）
- 有專業攝影的空間照嗎？幾張？
- 有產品／器材的擺拍照嗎？
- 有療程進行中的畫面嗎？（不露臉的手部特寫、產品質地特寫等）
- 有你本人（或美容師）的專業形象照嗎？
- 有客人的前後對比照嗎？**如果有，是否取得書面同意？**

> 說白一點：韓系乾淨風格的成敗**九成在照片**。設計再好，配上手機隨手拍的日光燈店內照，出來的感覺不會是「純淨」而是「素」。如果現有素材不足，我會建議先安排一次品牌攝影（半天約 NT$8,000–20,000），這筆錢的效益比升級網站方案高很多。

🟢 **C5.** 網站需要幾種語言？（只要繁中／繁中＋英文／要加韓文）

## D. 行銷與 IG 的關係

🟡 **D1.** IG 帳號的現況：帳號名稱？粉絲數？目前多久發一次？是專業帳號嗎？貼文以什麼內容為主（療程紀錄／保養知識／客人成果／個人生活）？

🟡 **D2.** 既然主戰場在 IG，你希望官網扮演什麼角色？

- [ ] （a）**成交頁** —— IG 負責吸引，官網負責讓她下單預約
- [ ] （b）**信任背書** —— 讓客人查得到、覺得正式可靠
- [ ] （c）**內容資產** —— 寫保養知識文章做 Google SEO，長期累積不靠演算法的流量
- [ ] （d）**Link in bio 集中頁** —— 取代 Linktree

> 這四個角色不衝突，但**首頁只能有一個最主要的目的**。如果你選（a），首頁第一屏就該是預約按鈕；如果選（c），架構會完全不同。

🟡 **D3.** 有在經營 LINE 官方帳號嗎？在台灣的美容業，LINE 通常比 IG 更適合處理預約與回訪 —— IG 負責曝光獲客，LINE 負責留客。你目前怎麼分工？

🟢 **D4.** 有做過付費廣告嗎？未來會投嗎？（會影響是否需要建 Meta Pixel、做落地頁）

🟢 **D5.** 想被 Google 搜到哪些關鍵字？（例：「台北 杏仁酸」、「信義區 果酸換膚」）

## F. 幾個你可能還沒想到、但值得現在就決定的事

🟡 **F1. 前後對比照要不要放？** 這是美容業最有說服力、也最容易觸法的素材。取決於 A1 的答案，可能完全不能放。如果要放，需要客人的書面同意書。**建議現在就開始準備同意書，並在每次服務時取得授權** —— 累積半年後你會有一批可以合法使用的素材，這比網站本身值錢。

🟡 **F2. 客人的個資怎麼處理？** 只要網站上有預約表單，就受個人資料保護法規範，需要隱私權政策與蒐集告知。如果同時收集健康狀況（例如「皮膚狀況問卷」、「是否懷孕」、「服用藥物」），那屬於**特種個資**，規範更嚴格。

🟡 **F3. 套票與預付款的法律風險。** 如果你賣次卡或課程，屬於預付型交易，受消費者保護法規範，可能需要符合定型化契約的規定。**這是美容業最常見的消費糾紛來源**，值得在網站條款頁面就寫清楚。

🟢 **F4. 取消與改約政策。** 被放鳥是美容業的日常成本。網站上明確寫出政策（例如「請於 24 小時前改約」）能省下很多爭執，也是要不要收訂金的前提。

🟢 **F5. 誰不適合做酸類煥膚？** 孕婦、正在用 A 酸、皮膚有傷口、剛做完雷射等。網站上主動寫清楚，既是專業展現，也是自我保護。
